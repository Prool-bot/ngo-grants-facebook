# Пошуковий архів NGO Grants

Джерело: загальнодоступний канал https://t.me/ngo_grants.

Архів створює окремий сценарій **Telegram Archive & Search**:
https://github.com/Prool-bot/ngo-grants-facebook/actions/workflows/telegram-archive.yml

Перший запуск завантажує всю доступну поточній Telegram-сесії історію. Надалі оновлення щодня о 03:17 UTC (06:17 за Києвом улітку, 05:17 узимку). GitHub може затримувати запуск. Щонеділі виконується повна звірка. Ручний запуск через **Run workflow** дозволяє оновити архів та виконати пошук.

## Файли після першого успішного запуску

- `index.json` — кількість дописів, дата оновлення, дата повної звірки, перелік місяців.
- `months/YYYY-MM.json` — тексти, дати UTC, ID, посилання на дописи, видимі й приховані URL, перегляди.
- `months/YYYY-MM.md` — тексти за місяцями для читання та пошуку через GitHub.

Розподіл за місяцями та фільтрація дат відповідають часовому поясу Europe/Kyiv. Дати в JSON збережені в UTC.

## Пошук у ChatGPT

У чаті з підключеним GitHub можна попросити: «Знайди в архіві NGO Grants гранти для кібербезпеки медіа» або «Перевір, чи публікували це посилання». Спочатку потрібно прочитати `index.json`, а потім потрібні місяці. GitHub індексує нові файли із затримкою; якщо пошук не знаходить матеріал, потрібно читати файли напряму. Архів не підтверджує чинність конкурсу — дедлайн і умови перевіряються на офіційному сайті організатора.

## Пошук без Telegram-авторизації

Після завантаження репозиторію:

```sh
python telegram_archive.py search 'цифрова безпека' --mode all
python telegram_archive.py search 'медіа журналіст кібербезпека' --mode any --since 2026-04-01
python telegram_archive.py search '"Front Line Defenders"'
python telegram_archive.py search --url 'https://example.org/call' --output output/results.json
```

Пошук охоплює весь архів; у консолі показуються 30 результатів, JSON містить усі збіги. Порівняння URL прибирає рекламні параметри `utm_*`, `fbclid`, `gclid` та фрагмент сторінки; значущі параметри, наприклад номер конкурсу, зберігаються. Пошук за словами шукає входження; тематичні синоніми задаються через `--mode any`.

## Оновлення і обмеження

Щоденна звірка перечитує нові дописи та останні 30 днів, враховуючи зміни текстів і видалення у цьому періоді. Давніші зміни, видалення та перегляди оновлюються під час щотижневої повної звірки або ручного `full_sync`. Збережені перегляди є знімком на момент останнього читання. Старі версії видалених публікацій можуть залишатися в історії Git.

Зберігаються лише публічні дописи вказаного каналу. Медіафайли, приватні чати, дані підписників, телефон і Telegram-сесія не експортуються. Немає операцій публікації в Telegram чи Facebook. Доступ використовує наявні GitHub Secrets: `TELEGRAM_API_ID`, `TELEGRAM_API_HASH`, `TELEGRAM_SESSION`. Архів публічний, як і репозиторій.

Якщо читання Telegram завершується помилкою, попередній архів не замінюється частковими результатами. Сценарій перевіряє цілісність архіву перед оновленням. Перше завантаження може потребувати додаткового запуску, якщо обсяг історії перевищує час виконання GitHub Actions. Фактичну успішність і час оновлення перевіряйте у `index.json` та Actions.
