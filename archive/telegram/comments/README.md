# Коментарі Telegram-каналу NGO Grants

Окремий сценарій GitHub Actions **Telegram Public Comments Archive** читає коментарі під дописами https://t.me/ngo_grants через наявну сесію Telethon.

**Приватність:** цей GitHub-репозиторій публічний. Архівувати коментарі дозволено лише тоді, коли прив'язана група обговорень має публічну адресу `@username`. Якщо група приватна, сценарій нічого не експортує. Автори, їхні ідентифікатори, фото, медіа, приватні чати, телефони з профілів і Telegram-сесія не експортуються. Контакти, зазначені в текстах самих коментарів, приховуються за простими правилами; гарантувати видалення всіх можливих персональних даних неможливо. Дані публічних коментарів, записані в Git, залишаються в історії комітів навіть після видалення.

## Структура

- `index.json` — список дописів із коментарями, останнє оновлення, кількість коментарів і посилання на файли.
- `posts/<id_допису>.json` — текст коментарів до одного допису, дата, посилання на коментар та ідентифікатор повідомлення; **без імен і ідентифікаторів авторів**.

## Оновлення

Автоматично щодня о **04:27 UTC** (07:27 за Києвом улітку, 06:27 узимку) перечитуються дописи за останні **45 днів**, у тому числі відповіді на коментарі. Для старіших коментарів можна запустити **Run workflow** вручну, змінивши `days` або вибравши `full_sync`. Тривалі запуски можуть перевищити обмеження GitHub Actions.

Доступ: https://github.com/Prool-bot/ngo-grants-facebook/actions/workflows/telegram-comments.yml

## Пошук

Для ChatGPT з підключеним GitHub спершу відкрити `archive/telegram/comments/index.json`, потім файл конкретного допису `archive/telegram/comments/posts/123.json`.

Локально:

```bash
python telegram_comments.py search 'як подати'
python telegram_comments.py search --post-id 3219
python telegram_comments.py search 'заявка' --since 2026-10-01
```

Читання не призводить до публікації чи відправлення відповіді в Telegram.
