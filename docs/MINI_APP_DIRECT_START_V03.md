# NGO Grants AI Mini App — запуск одразу після «Розпочати» (v0.3)

У публічному тестуванні заявник повинен мати **один очевидний шлях**:

1. Перейти до чинного бота **@ngogratsAI_bot**.
2. Натиснути **«Розпочати»** (Start) у Telegram.
3. У першій відповіді бота натиснути **«🤖 Відкрити грантового помічника»**.
4. Пройти анкету та, якщо бажає, замовити каталог.

Команда `/assistant` більше **не потрібна** для входу; її залишено як резервний варіант для старих посилань і користувачів. Після `/start` бот надсилає **одне повідомлення** з reply-keyboard (це потрібно для штатного Telegram `sendData`). Окрім кнопки Mini App, клавіатура має збережені команди `/request`, `/catalogs`, `/help`, `/status`. Початкові внутрішні алгоритми створення каталогу, обмеження, D1, webhook, архів та розклад GitHub Actions не змінюємо.

## Розгортання

- `worker/patch_live_worker_mini_app_start_v03.py` — суворо обмежена вставка в `handleTelegram` і оновлення заголовка `GET /mini-app` із `0.2` до `0.3`. Дотримується чинної версії й забороняє повторний patch.
- `worker/build_mini_app_start_v03_candidate.py` — зчитує чинний Worker лише у пам'яті GitHub runner і перевіряє, що активна затверджена v0.2.
- `tests/test_mini_app_start_direct_worker.mjs` — перевіряє справжній JS нового Worker із мокованим Telegram: `/start`, `/start referral`, старий `/assistant`. Ні реальних повідомлень Telegram, ні записів D1 під час тестування.
- `worker/deploy_worker_mini_app_start_v03.py` — інкапсульований випуск 0,01% canary → health, HTML і недоступність приватного маршруту → 100% або автоматичний відкат до v0.2.
- `scripts/mini_app_start_v03_edit_post.py` — **редагує** раніше опублікований допис `https://t.me/ngo_grants/3813`, а не створює новий. Прибирає вимогу `/assistant`; має одноразовий маркер GitHub до звернення до Telegram.
- `.github/workflows/mini-app-direct-start-v03.yml` — загальна оркестрація, після успішного деплою робить одне редагування анонсу.

## Межі безпечних змін

Не створюємо нового Telegram-бота, дубліката допису чи тестового замовлення. Однакова заявка через Mini App продовжує викликати наявний `createRequest` з його серверними обмеженнями. Пропонуємо реальним заявникам надсилати відгуки коментарями до старого допису, щоб не розривати обговорення.

Відкритий реальний E2E для першого добровільного замовлення контролюється в GitHub Issue #11.
