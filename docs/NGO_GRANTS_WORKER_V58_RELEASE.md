# NGO Grants AI — Telegram AI-меню v5.8 (7 листопада 2026)

**Стан:** v5.8 розгорнута на чинному Cloudflare Worker `ngo-grants-instant-bot`.
Пошуковий Python-двигун — v5.7. Файли архіву, D1-таблиці, секрети, ліміти
та публікації Telegram не змінено. Перемикання вебхука не виконувалося.

## Покращення меню

1. **Тип заявника:** ГО/БФ, комерційна організація/ФОП, фізична особа,
   рада/територіальна громада, заклад освіти/науки або всі категорії.
2. **Сфери:** кілька незалежних тематичних напрямів; немає вимоги, щоб
   один грант фінансував їх усі одночасно.
3. **Географія:** Україна, конкретна область, міжнародні конкурси або всі.
4. **Конкретна діяльність:** уточнення користувача з перевіркою приватних
   даних і максимальною довжиною 180 символів.
5. **Додаткові запитання:** відокремлення ГО від ради, фізособи від ФОП,
   спеціальних програм для жіночого бізнесу від загального підприємництва;
   при трьох сферах без уточнення — питання про конкретну діяльність.
6. **ШІ-підказка:** за потреби Cloudflare Workers AI
   `@cf/meta/llama-3.1-8b-instruct-fp8` пропонує **одне** питання
   до вже введеної теми. Не редагує заявку, не просить контакти,
   не витрачає добовий каталогний ліміт; користувач може пропустити.
   Якщо Workers AI недоступний — обробка залишається працездатною
   завдяки детермінованим правилам.
7. **Роль:** основний заявник, партнер або обидві ролі.
8. **Тип фінансування:** лише проєктні гранти або всі види підтримки.
9. **Підтвердження:** підсумок усіх параметрів і надсилання тільки після
   натискання «✅ Знайти гранти». Один запит/день, не більше 3 каталогів/день
   і 2-годинний інтервал між публікаціями зберігаються.

## Зв’язок із пошуковим алгоритмом

Worker зберігає в наявній таблиці `settings` (без міграції) поля:
`audience`, `sectors`, `custom_sector`, `geo`, `region`,
`detail`, `applicant_role`, `funding_format`.
Python `ngo_grants_ai.py` v5.7 вже валідує та фільтрує ці поля.
Історичні D1-записи з попереднім форматом залишаються сумісними.

## Оновлення без розкриття вихідного коду

Вихідний код Worker отримує **сам GitHub Actions runner** через Cloudflare API;
він не друкується в logs та не зберігається в публічному репозиторії.
`worker/patch_live_worker_v58.py` містить тільки контрольовані модифікації
v5.2, з перевіркою **кожної** точки вставлення.

- `worker-menu-v58-ci.yml`: локальний JavaScript syntax-check +
  16 тестових перевірок екранів, уточнень та поведінки AI без Telegram API
  і без D1-записів.
- `stage_worker_v58.py`: завантаження **неактивної** версії Cloudflare
  із суворим успадкуванням секретів BOT_TOKEN, SYNC_SECRET, WEBHOOK_SECRET,
  прив'язки DB та додаванням Workers AI `AI`.
- `worker-menu-v58-smoke.yml`: перевірка неактивної версії та прив’язок.
- `deploy_worker_v58.py`: canary 0,01%, запит з
  Cloudflare-Workers-Version-Overrides, перевірка HTTP 200 для /health
  та HTTP 403 без авторизації для /internal/pending; після успішного
  smoke — 100% v5.8, інакше автоматичне відновлення попередньої версії.

## Відновлення попередньої версії

За потреби відкрийте Cloudflare → Workers & Pages →
`ngo-grants-instant-bot` → Deployments і використайте функцію Rollback
до попереднього розгортання, або керуйте версіями через
`POST /accounts/{account_id}/workers/scripts/ngo-grants-instant-bot/deployments`.

**Не** змінюйте D1, токени чи webhook; вони не залежать від версії
модульного коду та залишаються чинними.

## Обмеження тестування

Тестування перевірило код і реальні health-ендпоїнти, але не створювало
реального Telegram-замовлення; фактичний досвід кінцевого користувача
потрібно перевірити в приватному чаті бота, **не натискаючи** кнопку
остаточної відправки під час тесту меню.
