# NGO Grants AI v5.7 — уточнення меню та жорсткий відбір

## Що розроблено

1. `catalog_guard_v57.py` — універсальна перевірка **типу заявника та
   позитивного предмета фінансування**. Результат: `direct`,
   `conditional` або `reject`. Перевірка виконується **тричі**:
   до ранжування, після рішення Cloudflare AI та перед публікацією PDF.
   Система не домислює партнерство, якщо його немає в тексті.
2. `worker/menu_refinement_v57.js` — готовий модуль уточнювальних запитань,
   контракт полів і підсумок перед фінальним підтвердженням. Не витрачає токени.
3. `tests/test_catalog_quality_v57.py` — регресії для семи проблемних
   каталогів жовтня–листопада (муніципалітети, освіта, жіноче підприємництво,
   міжнародні заявки, права людини, бізнес, фізособи).
4. `ngo_grants_ai.py` — підтримка опцій `applicant_role` (`lead`,
   `partner`, `either`) і `funding_format` (`any`, `grant_only`),
   а також додаткових типів заявників `municipal`, `institution`.
   Старі payload з D1 не зламаються.

## Запропонований порядок AI-меню (попередня домовленість)

**Крок 1.** Тип заявника: ГО/БФ, бізнес/ФОП, фізособа, рада/громада,
заклад освіти/науки або без обмежень.

**Крок 2.** Вибір сфери/сфер. Якщо кілька окремих видів діяльності, шукати
**кожен незалежно (OR)**, а з типом заявника й географією — **AND**.

**Крок 3.** Географія — вся Україна, конкретна область, міжнародні конкурси
або без обмежень.

**Крок 4.** Діяльність/проєкт (до 180 символів): що фінансується, хто
бенефіціар і кому потрібна підтримка.

**Перед підтвердженням.** Для неоднозначних комбінацій запитати максимум
два уточнення. Наприклад: «ГО чи територіальна громада як заявник?»,
«Фізособа чи ФОП?», «Лише жіночі бізнес-програми чи будь-які бізнес-гранти?»
Користувач **бачить підсумок** і може змінити відповіді. До натискання
«Підтвердити» не списувати денний запит і не створювати чергу.

## Важливе обмеження розгортання

Поточне Telegram-меню працює на **Cloudflare Worker**, вихідного файлу
якого немає в репозиторії `ngo-grants-facebook`. Модуль
`worker/menu_refinement_v57.js` **ще не підключений до продакшн Worker**.
Не замінювати ним наявний Worker цілком: це адаптер, а не весь код.
Для активації UI потрібно отримати вихідний код наявного Worker, інтегрувати
модуль у існуючий сценарій та розгорнути Worker з правами на Workers Scripts.
Секрети Telegram/Cloudflare залишаються без змін.

До активації UI Python уже фільтруватиме всі наявні структуровані запити
за новою суворою логікою, не змінюючи текстів або параметрів раніше
опублікованих каталогів.

## Тестування і реліз

- PR запускає лише нову `NGO Grants AI v5.7 Quality CI` з read-only правами.
- Немає доступу до Telegram token, CF AI token, gateway sync чи автопублікації.
- Після успішного CI власник вручну зливає PR до `main`.
- Існуючий розклад обробки черги, ліміти 1 запит/день,
  3 каталоги/день та 2-годинна пауза **не змінюються**.
- Якщо прямих відповідних грантів немає — зберігати чесний результат
  «не знайдено», а не створювати каталог із сторонніх конкурсів.
